# 🎮 Graphics Engine C++ (OpenGL)

A modular 2D graphics engine built in C++ using OpenGL. Designed for learning, experimentation, and extensibility, this engine supports sprite rendering, color tinting, basic transformations, and shader effects. Ideal for developers exploring graphics programming or building custom game tools.

---

## 🚀 Features

- ✅ Sprite rendering with texture loading (PNG)
- 🎨 Color tinting via fragment shader
- 🧭 Orthographic camera setup
- 🧱 Modular architecture with Sprite and Shader classes
- 🧪 Easy shader experimentation (vertex & fragment)
- 🛠️ Built with GLFW, GLAD, GLM, and CMake

---

## 🧰 Dependencies

- OpenGL 3.3+
- GLFW
- GLAD
- GLM
- stb_image

Install via your package manager (e.g. `apt`, `brew`) or include manually.

---

## 🧪 Getting Started

```bash
git clone https://github.com/yourusername/graphics-engine-cpp.git
cd graphics-engine-cpp
mkdir build && cd build
cmake ..
make
./graphics-engine-cpp
```
